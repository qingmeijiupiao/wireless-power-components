# Wireless_power 配对实机验收

适用：button、emergency_stop、meter_lite、meter_pro_v2。先将参与测试的设备全部刷本次固件，第一轮保留 NVS。按钮交互保持原短按关、长按 1 秒开，本次没有增加长按配对。

## 必测顺序

| 测试 | 操作 | 期望 |
| --- | --- | --- |
| 原绑定升级 | 保留两端 NVS，重启后控制 | 原绑定继续有效；开关只保留首个目标 |
| 原 MAC 重配 | 两端都不擦 NVS，重配三次 | 不增加绑定条数，结束后可控制 |
| 单边清空 | 分别只清急停 NVS、只清功率计 NVS，每种重配三次 | 开启目标配对窗口后，在约 15 秒扫描窗口内收敛；记录失败原因、信道和耗时 |
| 双边清空 | 两端清空 NVS 再配对 | 成功保存；两端断电重启后仍可控制 |
| 失败保旧 | 开关已配 A，尝试配不可达 B，或中途取消 | A 记录保留，失败退出后仍可控制 A |
| 切换目标 | 开关已配 A，再成功配 B | 开关记录只有 B；不能再控制 A。A 的历史记录需在 A 本机手动解绑 |
| 星形绑定 | 同一功率计依次配三只开关 | 三只均可控制，按 MAC 独立维护电量和在线状态 |
| 满容量 | 已存三只，再配第四只；然后重配原任意一只 | 第四只明确失败；原设备重配成功且数量不变 |
| 错误角色 | 开关对开关、功率计对功率计 | 新协议设备被角色策略拒绝 |
| 多候选 | 同信道两台功率计同时开配对窗口 | 拒绝歧义候选；关闭其中一台窗口后再配成功 |
| 迟到确认 | 在确认阶段拉远、屏蔽或断电，再恢复重新配 | 不误报旧事务成功，不覆盖旧绑定；重新配后收敛 |
| 射频生命周期 | 发送/配对期间断 USB、睡眠唤醒、WiFi 重启 | 没有旧 ON 重传、崩溃或卡死；恢复后可重新发送 |

不同信道的多个候选目前可能只发现其中一个，不能以此证明全环境唯一。测试应一次只开启一台目标窗口。

## 多急停仲裁

同一功率计绑定两只急停和一只按钮，分别测试 Lite 与 Pro V2：

1. 急停 A 按下时，B 和按钮发送 ON，以及功率计本地/Web/CAN 开启，都应被拒绝，OFF 始终允许。
2. A、B 同时按下，只释放一只仍不能开启；全部解除并完成控制同步后方可开启。
3. 一只已识别的急停断电/失联，超过 3 秒应关闭输出并禁止开启；普通按钮离线不触发此联锁。
4. 功率计重启后，已保存急停在有效心跳到达前禁止开启。急停恢复连接后检查原输出状态与解锁动作，避免意外开启。
5. 急停正在配对、换目标或触点切换时，检查输出保持关闭、旧发送被取消、配对结束后需要符合原急停释放/启动交互。

## 兼容和日志

- 额外测试新旧固件混用。旧协议可配对，但无法保证对端落盘确认，也没有角色筛选/多急停联锁心跳；多急停功能要求参与设备升级。
- 旧绑定角色未知时，新急停心跳会识别并补写角色；此前不能按急停角色执行离线联锁。建议旧绑定升级后先连接一次再重启验证。
- 记录设备版本、两端 MAC、NVS 是否清空、当前 WiFi 信道、两端串口日志、配对耗时和绑定数量。失败要保留结果中的 error/legacy，区分请求超时、歧义、容量满和 NVS 写入错误。
- 确认阶段断电可能留下单边记录；重新开启双方配对应收敛，不要求当前版本自动恢复跨重启事务。

主机自动化测试已覆盖握手确认、NVS 失败、旧绑定保留、迟到发送回调、取消代际、ACK 保留及每 MAC 状态/联锁过期；这些不能替代以上射频与触点验收。
